What is measured?

Each bar is wall-clock time per step, including diffusion, statistics and synchronization. Initialization, warm-up, frame transfers and rendering are excluded. CUDA also records device time with CUDA events. Speedup = CPU time ÷ backend time; small grids may run faster on the CPU.

Verification compares final maximum temperature against the CPU reference within 0.001 °C. A missing GPU is reported as skipped. This is a teaching benchmark, not a hardware certification.
